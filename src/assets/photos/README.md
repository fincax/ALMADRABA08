# Fotografías

Deja aquí los archivos con el nombre del hueco que ocupan. La web los
recoge sola en la siguiente compilación — no hay que tocar código.

| Archivo | Dónde sale |
| --- | --- |
| `hero.jpg` | Portada a sangre |
| `casa.jpg` | Sección «La casa» |
| `salon.jpg` | Galería · salón-comedor |
| `porche.jpg` | Galería · porche y jardín |
| `cocina.jpg` | Galería · cocina |
| `dormitorio-principal.jpg` | Galería · dormitorio principal |
| `dormitorio-segundo.jpg` | Galería · segundo dormitorio |
| `bano.jpg` | Galería · baño |
| `piscina.jpg` | Galería · piscina y zonas comunes |
| `playa.jpg` | Zahara · playa o dunas |
| `sierra.jpg` | Zahara · Sierra de la Plata |
| `pueblo.jpg` | Zahara · detalle del pueblo |

Sirve `.jpg`, `.jpeg`, `.png`, `.webp` o `.avif`. Sube el original grande:
la compilación genera las versiones ligeras (AVIF y WebP, varios tamaños).

Un hueco sin archivo sigue mostrando su placeholder, así que se pueden ir
subiendo de una en una.
